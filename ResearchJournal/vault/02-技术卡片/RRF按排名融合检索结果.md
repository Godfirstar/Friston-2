# RRF按排名融合检索结果


## 2026-10-19 · [[01-版本记录/2026-10-19_155456-099b9e8b79]]

RRF 根据各通道中的名次累加贡献，避免直接相加尺度不同的原始分数。

本次 `hybrid_search.py::hybrid_ranked_search` 使用 `Σ 1/(60+rank)`；常量来自 `RRF_K`，名次从 `enumerate(..., start=1)` 开始。dense 过滤后重新编号，原始相似度不进入公式。

它融合的是检索排名，不能把结果解释为事实置信度，也不等同于神经重排。应能手写按片段 ID 累计与排序的核心过程。
